A one-page newspaper front page for Saturday 21 November 2026. The
image is drawn entirely by `main.py` using only the Python 3.13
standard library: a hand-built 5x7 pixel font, integer raster
drawing and a small PNG writer. No image assets, no fonts, no
network. Run it and it writes `entry.png` (1024x1024):

    MAKEFUN_OUTPUT_DIR=out python3 main.py

## The four stories

1. **World court rules Myanmar committed genocide against the
   Rohingya** — the International Court of Justice in The Hague
   hands down its landmark verdict.
2. **Trump, Xi and Putin meet in Shenzhen** — the three leaders
   hold a trilateral summit on the APEC sidelines.
3. **Russian missile crashes in Poland** — Warsaw calls it a
   provocation as Russia pounds Ukraine anew.
4. **6.9 quake shakes Peru's Andes** — tremors felt in Lima, no
   casualties reported.
